## 桌面操作

- 单击动画区域：按上表编号切到当前动作的下一组；第 5 组后回到第 0 组。播放后恢复随机动作。
- 双击动画区域：换下一只伙伴。系统双击判定期间会等待，避免同时触发单击切动作。
- 拖动动画区域：移动窗口，不切动作或形象。
- 右键可选“下一个动作”或“下一个伙伴”；辅助功能同样提供这两个操作。
- 手动切到喝水动作不记录喝水量；点击水杯才新增喝水记录并优先播放喝水动作。
- 自定义图集有喝水帧段时，单击在普通动作与喝水动作之间切换；只有普通帧段时重新播放该段。
- 系统减少动态效果或暂停动画时保留静态展示。

听歌动作每帧 0.22 秒，连续播放 1–3 轮后回到日常动作；工作、加班和打卡后均有机会随机出现。哼歌和音乐用嘴型及音符表现，不播放实际音频。
