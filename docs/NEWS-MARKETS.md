# AIBot 新闻与市场行情

消息面板输入以下短语，AIBot 直接查询公开数据源，不经过 OpenRouter，不要求 API Key：

| 功能 | 示例 |
|---|---|
| 新闻速览 | 新闻、今日新闻、news |
| 经济新闻 | 经济新闻、财经新闻、business news |
| 时政新闻 | 政治新闻、时政新闻 |
| 主题新闻搜索 | 搜索中东石油战争的相关新闻、查找 AI 芯片相关报道、新闻搜索：油价、search news about oil prices |
| 黄金期货 | 黄金走势、黄金行情、gold |
| 比特币 | BTC走势、比特币行情、bitcoin |
| 股票市场 | 股市走势、股市行情、stock market |
| 全市场 | 市场行情、大盘、金融市场、markets |
| 单独指数 | 纳指、道指、A股走势、日经走势 |

## 数据源与展示口径

- 新闻：使用[中新网官方 RSS](https://www.chinanews.com.cn/rss/)、[BBC RSS](https://feeds.bbci.co.uk/news/world/rss.xml)、[CNBC RSS](https://www.cnbc.com/id/100727362/device/rss/rss.html)。经济主题切换财经/商业订阅；时政主题使用中新网时政和海外国际频道。默认使用中新网即时新闻，未使用实测存在格式错误的要闻导读订阅。
- 每个来源最多展示 4 条近 48 小时新闻，按发布时间倒序、按原文 URL 去重；不同媒体保留分组。这里是近期标题速览，不声称做了全网热度排名或跨语言事件聚类。
- 显示标题、发布时间、来源和原文链接；不抓取或转载文章全文。标题保留媒体原文，界面说明支持 App 内中英文切换。
- 行情：Yahoo Finance chart 公开端点。覆盖纳斯达克综合指数、道琼斯工业指数、上证综合指数、深证成指、日经225、BTC/USD、黄金期货 GC=F。黄金明确为期货，非现货或人民币金价。
- 展示最新报价、较前一日线收盘涨跌幅、可用近月样本变化和最近最多 10 个日线收盘值，所有时间标注 UTC。按交易所时区识别前一交易日期，避免使用月度接口的区间前收盘价作为日涨跌基准。末个日线点可能未收盘；BTC 日线变化不是滚动 24 小时变化。
- 每次输入重新查询，无伪造报价或静默旧缓存兜底。超过 24 小时的报价标注可能休市或延迟；单个来源/标的失败不会隐藏其他成功项。Yahoo 此接口没有本项目可依赖的官方稳定性承诺，可能限流或改变响应格式。

## 主题新闻搜索

直接识别“搜索/查找/查一下 + 主题 + 相关新闻/相关报道”和 `search news about ...` 等表达，提取主题后并行请求 Google News 与 Bing News 的公开 RSS 搜索，不需要配置搜索 API Key。

- 保留关键词中的空格、大小写及 `&` 等字符，使用 URL query items 编码。中文主题使用中文地区参数，英文主题使用英文参数；不自动翻译查询关键词。
- 客户端只展示近 7 天报道，最多 16 条，每家媒体最多 3 条；按报道 URL 和规范化标题去重，再按媒体分组，每组按时间倒序。这里不是全网完整搜索或 AI 事实核验。
- 媒体名称取自 RSS `source` / Bing `News:Source`，不是把 Google 或 Bing 当作报道媒体。Bing 包含原始报道地址时提取它；Google 不透明报道链接保留为聚合跳转地址，不伪造原文链接。
- 展示主题、抓取时间、媒体、标题和发布时间。标题保留原文，说明文案按 App 语言切换。
- 部分源失败时保留其余结果并说明；全部失败与零结果有不同提示。缺失主题/超过 200 字时本地提示，不发起搜索请求。
- 此功能使用公开但没有稳定 API 契约的搜索 RSS，服务可达性及结果覆盖受网络和上游索引影响，不会回退到模型编造报道。查询主题会发送到两个搜索源。

## 实现

`AIBot.interpret` → `LocalBotIntent.information` → `AssistantStore.fetchInformation` → `BotInformationClient`。

`BotInformationRequest` 保守匹配完整触发短语，避免把一般新闻讨论或“提醒我14:00看新闻”错误截获。网络请求、RSS/JSON 解码和中英文格式化在 `Sources/WorkdayCore/BotInformation.swift`；App 层负责消息 UUID、保存、取消、打字机资格和未读标记。

请求并行执行，每个请求超时 15 秒；只接收成功 HTTP 响应，拒绝超过 2MB 的响应。XML 不解析外部实体，文章链接只允许 HTTP(S)。消息先显示获取中状态，再更新同一个 UUID；支持停止、关闭面板后继续接收，以及长消息独立展开。查询结果通过现有历史机制持久化，后续当天普通模型对话仍可能纳入这些已完成问答。
