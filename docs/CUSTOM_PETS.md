# 自定义序列帧

普通动画停在第一帧时，先检查“普通动画帧数”是否为 1。新版对新导入图集默认开启“自动计算普通动画帧数”：填写行列后采用全部网格；指定喝水起始帧后采用它之前的帧。例如 6×6 图集、喝水 31–36，会自动得到普通 30 帧。开启喝水时默认最后一行，请按实际内容确认。旧配置会显示单帧提示和“自动修正为 30 帧并播放”按钮；点击后保存即可应用到桌面。关闭自动模式可保留自选帧数或有意的单帧展示。自动模式不识别画面内容，喝水从第 1 帧开始时仍使用全部网格作为普通动画。

桌面单击自定义伙伴：已配置喝水帧段时，在普通动作和喝水动作之间切换；只有普通帧段时从头重播。单击动作预览不增加喝水量，双击仍切换形象。

macOS：设置 → 通用 → 自定义序列帧。iOS：今日 → 设置 → 自定义序列帧。

1. 导入一张 PNG 图集，透明背景效果最佳。每帧必须等尺寸，按从左到右、从上到下排列。
2. 填写列数、行数、有效帧数及每秒帧数。例如内置基础图集为 6 列、4 行、24 帧；可使用 8 fps。
3. 选择循环或往返播放，查看实时预览。往返不会重复播放两端帧。
4. 可开启“独立喝水动画”，指定从 1 开始的首末帧。喝水成功后播放该段一次，再恢复普通循环；没有指定时保持普通动画。
5. 保存后应用；取消不替换原伙伴。有效的自定义伙伴会加入桌面双击切换顺序。

限制：单张 PNG 最大 32 MB、4096×4096；行列各最多 32，总格数最多 256；尺寸须能整除网格；帧率 1–30。暂不导入 GIF、APNG、视频或多个独立帧文件。

图集复制到应用本地 Application Support/XiaBanLa/CustomPets，原文件移动后仍能使用。macOS 沙盒只读取用户主动选择的文件。替换或取消时仅清理本应用创建的副本，不改动原始图片。设置中的预览支持暂停，系统减少动态效果会停留在静帧。
